# video/ — music video pipeline

Remotion workspace for turning VoynichLabs tracks into music videos. Separate from the Astro site: own `package.json`, own `node_modules`, never touched by `npm run build` at the repo root.

Plan: `docs/2026-10-04-music-video-pipeline-plan.md`. First video: **System Prompt** (Latent Space track 10). Public storyboard: `/music/video/system-prompt`.

## Layout

```
data/{slug}/scenes.json      scene book: source of truth for the composition AND the site storyboard page
data/{slug}/timing/*.json    generated by scripts/analyze.py (committed, small)
scripts/analyze.py           Whisper word alignment against the lyrics file + librosa beat grid
scripts/sync-assets.mjs      copies each song's mp3 from ../public into video/public (gitignored)
src/Root.tsx                 registers compositions
src/SystemPrompt.tsx         the System Prompt video
src/components/              Terminal, ShotSlot, Captions (song-agnostic)
src/lib/timing.ts            typed access to scenes/words/beats
```

Not committed: `node_modules/`, `.venv/`, `public/audio/`, `out/`, `clips/`, `stems/`, `.env`.

## Setup (Windows, from `video/`)

```bash
npm install
python -m venv .venv
.venv/Scripts/python -m pip install faster-whisper librosa soundfile
node scripts/sync-assets.mjs
```

## Commands

```bash
npm run studio                          # live preview / scrubbing in the browser
npm run render:system-prompt:preview    # 1280x720 animatic -> out/
npm run render:system-prompt            # 1920x1080 master -> out/
npm run typecheck
```

Re-run timing analysis (only needed if the audio or lyrics change):

```bash
.venv/Scripts/python scripts/analyze.py system-prompt ../public/audio/latent-space/system-prompt.mp3 ../public/audio/latent-space/system-prompt_lyrics.txt
```

Publishing an animatic to the site: copy the render to `../public/video/{slug}/animatic-vN.mp4` and update the page.
